Run in Colab: four short steps

  1. Sign in to Google and open a notebook using its Colab button above.
  2. Use a standard CPU runtime. A GPU is unnecessary.
  3. Choose Runtime → Run all. The first setup cell retrieves the supporting files and installs dependencies.
  4. Follow the notebook in order. In Classroom Labs, change forecasts or parameters and rerun the relevant cells.

Classroom Labs performs fresh numerical calculations. L10B displays saved Llama replies and saved tool results, with no new model call or electrical solve. The default route needs no API key, language-model download or GPU.

Explain what each result covers

The examples use synthetic or reduced networks. The fresh classroom cases and L10B's separate recorded studies are clearly labeled. A model explanation does not prove that a plan passes its limits; recorded REVIEW or PENDING outcomes remain unresolved. The final control-room walkthrough proposes an advisory pilot, not a deployed utility system.
