Run in Colab: four short steps

  1. Sign in to Google and open a notebook using its Colab button above.
  2. Use a standard CPU runtime. A GPU is unnecessary.
  3. Choose Runtime → Run all. The first setup cell retrieves the supporting files and installs dependencies.
  4. Follow the notebook in order. In Classroom Labs, change forecasts or parameters and rerun the relevant cells.

Classroom Labs performs fresh numerical calculations. Model replies and recorded experiment timings remain archived. The default route needs no API key or model download.

Teach the evidence with its scope

The examples use synthetic or reduced networks. Recorded numerical checks, language-model explanations and human approval are different events. The walkthroughs preserve their original REVIEW or PENDING outcomes; the guides explain each study’s assumptions.
