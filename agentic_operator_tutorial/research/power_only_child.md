# Additional power-agent studies

Use **E03 Grid-Agent** to teach the state-driven planner/executor/validator loop and the difference between simulated rollback and physical reversibility. Use **E04 VeraGrid-Agent** as the stronger additional measured comparison: it provides exact question-level counts and a public benchmark repository. Their tasks differ, so do not rank the papers against one another.

The JSON provides source-map-ready E03/E04/E04C entries, executable workflow descriptions, raw chart counts, exact paper locators, code status, reporting ambiguities and three slide suggestions per study. It preserves missing trial counts and uncertainty rather than inventing them.

Primary sources: [Grid-Agent v3](https://arxiv.org/pdf/2508.05702v3), [VeraGrid-Agent v1](https://arxiv.org/pdf/2607.25155v1), [VeraGrid-Agent author implementation](https://github.com/Shivanshu-11/veragrid-llm-benchmark).

The two strongest original teaching visuals are an action/validation cycle drawn from E03 Figure 1 and a file/solver/targeted-read trace drawn from E04 Figure 2. A new simulator trace would need its own execution and validation; none was run during this research.
