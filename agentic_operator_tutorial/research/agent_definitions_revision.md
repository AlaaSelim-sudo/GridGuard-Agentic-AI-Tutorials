# Introductory definition revision

The JSON companion contains five bibliographic source entries, their verified locators, a role comparison, one hypothetical v43 study, six slide outlines, and an optional native TikZ sketch. No shared content or diagrams were edited.

Recommended opening sequence: classical agent → this tutorial's working meaning of agentic AI → agent versus callable tool → workflow/control distinction → orchestration versus domain platform → engineering contract. The six outlines can become four slides by merging 1+2 and 5+6.

Two source/version details matter:

- The accessible Russell/Norvig chapter is an older author-hosted sample with printed pp. 32–58, although its current URL contains `4th-ed`. The JSON cites the second edition and records the mismatch rather than labeling that file fourth-edition text.
- Wooldridge/Jennings' searchable author HTML is an earlier 1994 draft; the bibliography points to the final 1995 paper. The section locators remain explicit.

Use the original working definition as a declared teaching convention, not a standardized quotation. The most useful organizing question is which component makes which decision under which constraints. The diagram suggestion is only a sketch, as requested.
