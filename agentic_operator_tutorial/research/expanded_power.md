# Additional power-system agent research

Reviewed 17 October 2026. P01–P03 support six core teaching slides; P04 can supply two optional comparison slides. All are research systems or benchmarks, not evidence of utility deployment. Full metadata and locators are in expanded_power.json, whose source_additions dictionary is ready to merge.

P01 makes the allowed action space concrete: show the locked model fields, permitted gains and a test-feedback loop before presenting success counts. Distinguish repeated sessions from distinct plant models. The open benchmark repository supplies a harness, but its dynamic task needs licensed/external simulators.

P02 supplies a testable evidence trail across heterogeneous records. Its main accuracy is a macro-average; the three families have unequal sizes. Use complete-answer and field-credit metrics together. The linked repository currently exposes only a README and license, so reproducible release has not been independently verified. Avoid similarly named power-grabbing or inspection benchmarks.

P03 supplies a measured reason for content-addressed state: follow one changed forecast or solver through the declared dependencies, then compare stage counts with wall time. Its numerical backends include surrogates and reduced-order simulation. A reused artifact can still be wrong if its input identity omits a relevant dependency.

P04 provides a useful caution about narrow solver agreement and inconsistent contingency rankings. Do not blend its implementation framework or evaluation with the later weather workflow.

Original figure opportunities and source pages are recorded in the JSON. New plots use author-reported numeric facts and clearly label calculations and uncertainty; they do not reproduce proprietary operating data. No shared builder, content or source map was changed.
