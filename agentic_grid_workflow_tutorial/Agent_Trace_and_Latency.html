T3 — Voltage: the actual Llama response and its timing boundary

The choice controls the permitted transition. For the OpenDSS record, Planner requests VERIFY_SAC_FIRST; Recovery requests USE_MPC_PLAN; Explanation returns REVIEW_EVIDENCE. These words neither solve an optimization problem nor authorize dispatch. Read the explanation beside the numerical gate result.

client_s is the calling code's elapsed interval. server_s converts Ollama's total_duration from nanoseconds. The two are nested measurements and must not be added. Cached prompts, model load state and different output lengths can affect latency. The payload options are recorded, but the records do not establish a controlled hardware benchmark.

The keyword parser asks for clarification; hybrid intake calls Llama once and the fixed downstream catalog finds a verified feeder candidate. This is a task-completion difference on one authored request, not proof of general restoration intelligence.

The short tie's physical rating remains 400 A; the operator imposes an additional 100 A ceiling. The selected 0.75 shedding parameter applies to noncritical load objects. It is not a statement that 75% of every load is shed. The recorded AC result serves 1,843.61 kW, including all 474.04 kW designated critical load, at 95.56% of the allowed current. T6 — Cyber: residual checking needs a trust assumption

Main C1–C4 show DC WLS estimation, isolated measurement corruption, stealth data of the form $a=Hc$, and a response using additional protected angle measurements. The attack lies in the measurement model's column space and can evade the residual test. The protected angles are extra inputs with assumed authenticity, not magically repaired attacked measurements. A deterministic redispatch and fresh true-model check provide the numerical response.

The same tools are available to fixed supervision. In the historical agentic record the numerical candidate passes the modeled check, but the language outcome is REVIEW. Read the actual reason, then identify which field the state machine must obey. The four-bus DC example does not validate an entire distribution network or a real security system.
