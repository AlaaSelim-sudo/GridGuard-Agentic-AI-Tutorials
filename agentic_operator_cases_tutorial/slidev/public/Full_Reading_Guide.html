How to teach this hands-on session

Format
80 static slides / 180.0 minutes. Getting started and agent basics: 17 slides / 30.0 minutes; Voltage support: 15 slides / 33.5 minutes; Service restoration: 14 slides / 28 minutes; Cyber response: 16 slides / 32 minutes; Llama walkthrough and operator practice: 18 slides / 56.5 minutes.
Prerequisite
Use the foundations tutorial first. This session follows the current Classroom Labs notebook through voltage support, service restoration and cyber response.
Evidence modes
Run the selected numerical cells to calculate results for your inputs. Archived model-response pools and historical evaluation records remain separately labeled. Editing L2 does not change the archived test_01 used by L3–L5, and editing the L8 sweep does not change the fixed L9 recovery fixture. No default cell calls an LLM or operates equipment.
Preparation
Give participants Participant_Lab_Guide.pdf. Open the one required notebook in Google Colab, sign in and use a standard CPU runtime. Run setup, wait for Ready, then follow the L labels in order. Keep both model switches at the stated defaults. The default route needs no API key, LLM download or GPU.
Stanford teaching bridge
Original grid teaching diagrams adapt task decomposition, evidence checking and explicit workflow specification from Monica Lam’s CS224V Lecture 1, with full lecture and paper references below. This notebook does not run WikiChat, Genie Worksheets or a theorem prover.
Facilitation
Follow each slide’s lab label and stable cell ID. Read the code, predict the result, run it, change the stated parameter and explain what changed. Each exercise has its own timed prompt; answers belong in the teacher notes and following debrief.

3. What makes this an LLM agent?

Timing
02:00–03:30 (1.5 minutes)
Slide content
A fixed script follows choices written in code. An LLM agent can choose a permitted next tool. Both can branch and use the same solvers. We must test whether model choice adds value.
Teaching notes
Use Anthropic’s attributed architectural distinction. A conventional program can contain feedback, branches, rules and sophisticated optimization. Those alone do not demonstrate an LLM agent. A generative model can also just write an explanation. In these records Llama makes bounded choices from an allowed list, receives tool evidence and may select another step. This is narrow agency, not unrestricted autonomy. The default class replays those choices.

9. Six terms we will use in the notebook

Timing
14:00–15:30 (1.5 minutes)
Slide content
Each term describes one job. The language model chooses among tools that do these jobs. A passing result applies only to the inputs, limits and parts of the network that were checked.
Teaching notes
MPC plans controls using a forecast. SAC supplies a proposal from a previously trained controller. MILP chooses whole loads while respecting the stated constraints. WLS finds the state that best fits the weighted readings. Evidence binding checks that inputs and command still match a stored result. Model scope means which network parts and physical effects were included. Also define p.u. as a value divided by its stated base: 1.0 p.u. is that base value. A thermal limit here is a current or flow limit. The objective or cost is the numerical score to optimize after required checks pass.
