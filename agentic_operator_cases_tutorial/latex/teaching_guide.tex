\subsection*{2. What is agentic AI?}
\textbf{Timing:} 01:00--02:00 (1 minutes)\par
\textbf{Slide content:} An AI agent chooses a tool, reads its result and chooses the next step toward a goal.\par
\textbf{Teaching notes:} Use the architectural definition in Anthropic, Building effective agents: an agent lets the LLM direct its process and tool use. Agentic AI is a broad term; here it means a system organized around this bounded loop. An AI agent is the component that chooses and follows steps. A tool is a permitted software function that returns a result. Point to the goal, model choice, executable tool, returned evidence and feedback arrow. The application stores case facts and prior results as the context supplied at the next model request. If a required check is missing, the outcome remains HOLD. Stop or return a proposal only under the fixed workflow rules. Do not imply that feedback alone establishes agency: conventional programs can also branch and loop. Our default notebook calculates engineering results now but replays the actual old Llama choices. No live model service is needed. Stanford source: Monica Lam, CS224V Agentic AI, Lecture 1: Introduction, Fall 2026, p.2 describes function calling and agentic workflows. The goal-and-feedback drawing is our grid teaching adaptation, supported by the separate bounded-agent architecture citation. This is not an original Stanford power-system diagram.\par

\subsection*{8. Language and decision checks}
\textbf{Timing:} 05:00--05:30 (0.5 minutes)\par
\textbf{Slide content:} The source example turns written facts into constraints for a solver.
In our lab, Llama requests a study. Python checks it. A person reviews it.\par
\textbf{Teaching notes:} This original diagram selection comes from the function row on p.53 of Monica Lam's introduction. It shows a clinical-trial example, not a power-system experiment. The language model translates written facts into an SMT representation; a separate solver derives a decision from those constraints. SMT means satisfiability modulo theories, a way to express and solve logical constraints. MaxSAT supports the lecture's search for conditions that change a decision. The lecture also states that the formalization may not be completely faithful, so correctness remains relative to the represented constraints. Our application is an analogy: Llama requests the permitted estimate or control tool and Python checks numerical limits. An operator must still confirm the trust assumption and review the proposed action. Our notebook does not run an SMT/MaxSAT solver or prove formal electrical safety. Preview the HOLD/PROPOSE distinction now; participants will calculate the L9 outcomes later with their stated model and trusted-data assumption.\par

\subsection*{57. What the residual measures}
\textbf{Timing:} 56:30--57:30 (1 minutes)\par
\textbf{Slide content:} Weighted least squares (WLS) fits the readings. Residual J measures the mismatch.
The true state is known in this simulation, not in a live control room.\par
\textbf{Teaching notes:} WLS means weighted least squares: find the state that best fits the readings, giving more influence to readings with smaller stated uncertainty. That weighting does not authenticate a reading. Here J is the residual mismatch statistic, not the voltage case's penalty score. Its chi-square alarm threshold is about 15.086272 for five residual degrees of freedom at a 1\% significance level. This calibration depends on the stated linear model and noise assumptions. An operator does not have the synthetic truth used to calculate the plotted state error. A small J does not establish that the readings are authentic.\par
