\clearpage\section*{Agent role map: Voltage: L10 MV archive}
\textbf{Read the case /\allowbreak{} Python}\par Read the load, forecast, current allowance and MV model scope.\par\medskip
\textbf{Choose a trial /\allowbreak{} numerical tools and Llama}\par Prepare MPC and saved-SAC candidates. Llama can request the declared initial studies or return review.\par\medskip
\textbf{Calculate /\allowbreak{} Python}\par Calculate the effects of each candidate using the declared three-phase linear model.\par\medskip
\textbf{Check /\allowbreak{} Python}\par Check case matching, voltage, current and inverter limits. Only passing candidates receive eligible scores.\par\medskip
\textbf{Refine /\allowbreak{} Llama, with a Python guard}\par Request less reactive power, then more PV output. Recalculate and check every changed setting. Python selects by verified cost and performs a final recheck.\par\medskip
Selected final current use: about 50.75\% of the allowance. This is the L10 MV archive, not the L2 experiment or P3 OpenDSS replay. The operator still reviews scope and missing checks.\par

\textbf{Read the case /\allowbreak{} Python}\par Keep the fault, available ties, critical loads, service goal and model scope in the shared case record.\par\medskip
\textbf{Choose a trial /\allowbreak{} numerical tools and Llama}\par Prepare the stated restoration catalog options; request the initial evaluations or review.\par\medskip
\textbf{Calculate /\allowbreak{} Python}\par Calculate total and critical service and the current used by each option.\par\medskip
\textbf{Check /\allowbreak{} Python}\par Reject the SHED\_\allowbreak{}065 trial at about 111.01\% of allowed current. Keep the passing SHED\_\allowbreak{}075 trial eligible.\par\medskip
\textbf{Refine /\allowbreak{} Llama, with a Python guard}\par Request bounded catalog changes and rank passing IDs. Python corrects the wrong cost order and rechecks the chosen plan.\par\medskip
Selected final service: about 1,843.61 kW total and 474.04 kW critical, at 91.87\% current use. This is not L6's six-node MILP. Physical switching order and operating permissions remain outside the result.\par
