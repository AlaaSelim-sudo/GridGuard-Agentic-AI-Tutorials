  4. Verification / Python: Check case matching, voltage, current and inverter limits. Only passing candidates receive eligible scores.
  5. Optimizer / Llama, with a Python guard: Request less reactive power, then more PV output. Recalculate and check every changed setting. Python selects by verified cost and performs a final recheck.

  3. Simulation / Python: Calculate total and critical service and the current used by each option.
