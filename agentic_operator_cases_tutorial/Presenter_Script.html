  2. Choose a trial / numerical tools and Llama: Prepare MPC and saved-SAC candidates. Llama can request the declared initial studies or return review.
  3. Calculate / Python: Calculate the effects of each candidate using the declared three-phase linear model.
  4. Check / Python: Check case matching, voltage, current and inverter limits. Only passing candidates receive eligible scores.
  5. Refine / Llama, with a Python guard: Request less reactive power, then more PV output. Recalculate and check every changed setting. Python selects by verified cost and performs a final recheck.
